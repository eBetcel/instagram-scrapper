# Fatia 2a — API do produto web — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API FastAPI do piloto: convites, login por link mágico, grupos com @s e seguidores, agenda e detalhes de eventos, imagens dos flyers.

**Architecture:** Subpacote `agenda/api/` com `criar_app(deps)` (fábrica de sessões, configuração, enviador de e-mail, storage e relógio injetados, como `Dependencias` no pipeline). Uma sessão de banco por requisição (commit no fim, rollback em erro). Rotas em três routers (`auth`, `grupos`, `eventos`), consultas em `consultas.py`, esquemas pydantic em `esquemas.py`.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, SQLAlchemy 2, Alembic, pydantic v2 (+ `email-validator`), pytest + testcontainers + `fastapi.testclient` (httpx), Mailpit.

**Spec:** `docs/superpowers/specs/2026-10-14-fatia-2-produto-web-design.md` (seções 3–7, 9 e testes da api da seção 10)

## Global Constraints

- Todas as rotas sob `/api`; erros `{"detail": "<mensagem em português>"}` com 401/403/404/409/422/429.
- Cookie `sessao`: `HttpOnly`, `SameSite=Lax`, `Path=/`, `Secure` se `COOKIE_SEGURO=true`; sessão de 30 dias.
- Link mágico `{APP_URL}/api/auth/verificar?token=<token>`, válido 15 minutos e uma vez.
- Limite de envio: 1 link por minuto e 5 por hora por e-mail.
- Tokens, sessões e convites guardam só `sha256` (hex) do valor.
- Código de convite: 8 caracteres de `ABCDEFGHJKMNPQRSTUVWXYZ23456789`, exibido `XXXX-XXXX`; hífen, espaços e caixa ignorados na entrada.
- `LIMITE_GRUPOS_POR_USUARIO = 10`, `LIMITE_PERFIS_POR_USUARIO = 30` (@s distintos nos grupos de que a pessoa é dona).
- Datas da agenda no fuso `America/Sao_Paulo`; padrão hoje até +7 dias; máximo 500 eventos.
- `alterado` = `evento_fontes.decisao = 'atualizacao'` criada nos últimos 7 dias.
- O e-mail de um usuário nunca sai em rota pública; o curador é `usuarios.nome`.
- Testes rodam em `backend/`: `uv run pytest -q`.

## Review Focus

1. Dois cadastros simultâneos com um convite de 1 uso: só um cria conta — o consumo é um `UPDATE ... SET usos_restantes = usos_restantes - 1 WHERE ... AND usos_restantes > 0 RETURNING id`, atômico (teste sequencial na Task 3: o segundo uso falha).
2. E-mail com maiúsculas/espaços ("  Fulano@X.com ") identifica a mesma conta (teste na Task 3).
3. Grupo de outra pessoa: PATCH, DELETE, adicionar e remover @ dão 403, e anônimo dá 401 (teste na Task 4 e Task 5).
4. Evento postado só por perfil fora dos grupos da pessoa não aparece na agenda, mesmo sendo do mesmo dia (teste na Task 6).
5. `GET /api/grupos/{slug}` sem sessão não expõe e-mail do dono nem quebra por falta de cookie (teste na Task 4).

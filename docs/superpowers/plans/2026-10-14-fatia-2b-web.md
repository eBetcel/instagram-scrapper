# Fatia 2b — Front web (Next.js) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** As páginas do piloto (`/entrar`, `/`, `/evento/[id]`, `/grupos`, `/g/[slug]`, `/conta`) sobre a api da Fatia 2a, com smoke tests Playwright do fluxo completo.

**Architecture:** App Next.js em `web/` (App Router, TypeScript, Tailwind). `next.config.ts` repassa `/api/:path*` para `API_URL_INTERNA`. Páginas são Server Components que chamam a api por `apiServidor()` repassando o cookie `sessao`; mutações são Client Components que fazem `fetch("/api/...")` e `router.refresh()`. Regras de data e formatação ficam em funções puras testadas com Vitest.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, Vitest, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-14-fatia-2-produto-web-design.md` (seção 8 e o smoke da seção 10; contrato da api na seção 7)

## Global Constraints

- Textos em pt-BR; datas e horas no fuso `America/Sao_Paulo` (`Intl.DateTimeFormat("pt-BR", { timeZone: "America/Sao_Paulo" })`), nunca no fuso do navegador.
- Mobile-first: layout de uma coluna até 640px.
- O navegador só fala com a origem do front (`/api/...`); nada chama a api direto.
- `hora_definida = false` → "horário a confirmar".
- Selos: ⚠️ alterado, ❌ cancelado, 🔴 esgotado, ⏸ adiado.
- Páginas logadas (`/`, `/grupos`, `/conta`) sem sessão → `redirect("/entrar")`; `/g/[slug]` e `/evento/[id]` são públicas.
- Portas de desenvolvimento: front 3000, api 8010 (`API_URL_INTERNA=http://localhost:8010`; a 8000 é de outro projeto nesta máquina).
- Comandos do front rodam em `web/`: `npm test` (Vitest), `npm run lint`, `npm run build`, `npm run e2e` (Playwright).

## Review Focus

1. Evento às 23h30 de São Paulo aparece no dia certo mesmo com o navegador ou o servidor em UTC (teste Vitest na Task 2, rodando com `TZ=UTC`).
2. "Fim de semana" numa segunda-feira aponta para o sábado e o domingo seguintes; num sábado, para hoje e amanhã (teste na Task 2).
3. Cookie vencido no meio do uso: páginas logadas redirecionam para `/entrar` em vez de quebrar (teste na Task 1: `apiServidor` com 401 chama `redirect`).
4. Mensagem de erro da api (422/429) aparece para a pessoa no formulário, sem texto técnico (teste na Task 3 e no e2e da Task 8).
5. Grupo público aberto por quem não tem sessão: o botão "Seguir" leva para `/entrar` e a página não pede login para ser vista (e2e na Task 8).

### Task 2: Datas, períodos e formatação

**Files:**
- Create: `web/src/lib/datas.ts`, `web/src/lib/formato.ts`
- Test: `web/src/lib/datas.test.ts`, `web/src/lib/formato.test.ts` (script `test` passa a rodar com `TZ=UTC`)

**Interfaces:**
- `type Periodo = "hoje" | "fim-de-semana" | "semana" | "mes"`; `intervalo(periodo: Periodo, agora: Date): { de: string; ate: string }` (datas `AAAA-MM-DD` em São Paulo): hoje = hoje–hoje; fim de semana = sábado–domingo desta semana (sábado/domingo: o próprio fim de semana); semana = hoje–hoje+6; mês = hoje–último dia do mês.
- `diaDe(iso: string): string` (`AAAA-MM-DD` em São Paulo); `agruparPorDia(eventos: Evento[]): { dia: string; eventos: Evento[] }[]` na ordem de entrada.
- `rotuloDia(dia: string, hoje: string): string` → "Hoje", "Amanhã" ou "sábado, 17 de outubro".
- `hora(e: Evento): string` → "21:00" ou "horário a confirmar"; `preco(e: Evento): string | null` → "Grátis" (`gratuito` ou `preco_max == "0"`/`"0.00"`), "R$ 40", "R$ 30 a R$ 60", `preco_texto`, ou `null`; `selos(e: Evento): string[]` na ordem alterado, cancelado, esgotado, adiado (ex. `["⚠️ alterado", "🔴 esgotado"]`).

- [ ] **Step 1:** Testes com as datas: `agora = 2026-10-19T02:30:00Z` (domingo 18/10 23h30 em SP) → `intervalo("hoje")` = 2026-10-18/2026-10-18 e `fim-de-semana` = 2026-10-17/2026-10-18; segunda 2026-10-19 15h → fim de semana 2026-10-24/2026-10-25, semana 2026-10-19/2026-10-25, mês 2026-10-19/2026-10-31; `diaDe("2026-10-19T02:30:00Z") == "2026-10-18"`; `agruparPorDia` separa 23h30 e 00h30; `rotuloDia`; `hora`, `preco` (os 5 casos), `selos`.
